# Portfolio Project 1

## Focus
- The connection between a frontend (JavaScript) and a backend (Python).
- User management, such as user creation, password changes and user deletion.
- Authentication via JWT cookies.
- Responsive design.
- Forms and user interactions. 

## Libraries & Frameworks
### Frontend:
- Vite
- React
- Declarative React Router
- Tailwind CSS

### Backend:
- Django
- Django Rest Framework
- dj-rest-auth
